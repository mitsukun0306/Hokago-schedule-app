# Hokago-schedule-app

放課後予定共有アプリ「afterclass」

## ロール
・スクラムマスター：ちはな
・リポジトリオーナー：みつ

## ゴール

友達同士で放課後や休日の予定をゆるく共有し、「一緒に勉強する」「遊ぶ」「部活後にご飯」などを調整できるアプリ。

## 利用する技術

フロントエンド: HTML, CSS, JavaScript（ES Modules・ビルド不要）
バックエンド: Python（標準ライブラリのみ・`pip install` 不要）

## 起動方法

```bash
python3 server.py
```

ブラウザで http://localhost:8000 を開きます。
ニックネームを入れるだけで始められます（データは `data.json` に保存されます）。

> `index.html` を直接ダブルクリックで開いても動きません。必ずサーバー経由で開いてください。

## 機能

| 機能 | できること |
| --- | --- |
| カレンダー | 月表示・週表示（時間軸）、今日へ移動、グループ別の絞り込み、日付タップで予定追加、週表示の空き枠クリックで予定追加 |
| スケジュール管理 | 予定の追加・編集・削除、終日／時間指定、繰り返し（毎日・毎週・毎月＋終了日）、場所・メモ、リマインダー、時間が重なる予定の警告、一覧・検索・絞り込み、出欠（参加／未定／不参加） |
| グループチャット | グループごとのリアルタイムチャット、未読数、予定カードの共有（チャットから出欠回答）、URL の自動リンク、自分のメッセージ削除、ブラウザ通知 |
| 共有 | 招待リンク・招待コード（LINE／メール／コピー／端末の共有機能）、予定リンク、予定のテキストコピー、`.ics` 書き出し（Google カレンダー・iPhone 等に取り込み可）、みんなの空き時間チェック |
| 通話 | グループでの音声・ビデオ通話（WebRTC）、ミュート、カメラ ON/OFF、画面共有、通話の最小化、着信通知、通話時間の記録 |

## ログインについて

- パスワードはありません。はじめてニックネームを入れるとアカウントとログインコードが作られます。
- ほかの端末で同じアカウントを使うときは、右上のメニュー →「ログインコード」を表示して、新しい端末のログイン画面に入力します。ログインコードはパスワードと同じなので人に教えないでください。

## 友だちのスマホから使う（同じ Wi-Fi）

起動時に表示される `http://192.168.x.x:8000` を開けば、チャット・予定・共有は使えます。

ただし **マイクとカメラ（通話）は https か localhost でしか使えない** ブラウザの決まりがあります。別の端末で通話するときは HTTPS で起動してください。

```bash
# 例: mkcert で証明書を作る（https://github.com/FiloSottile/mkcert）
mkcert -install
mkcert 192.168.x.x localhost
SSL_CERT=192.168.x.x+1.pem SSL_KEY=192.168.x.x+1-key.pem python3 server.py
```

インターネット越し（別々のネットワーク同士）で通話する場合は、NAT を越えるための TURN サーバーが必要になることがあります。`ICE_SERVERS` 環境変数で指定できます。

```bash
ICE_SERVERS='[{"urls":"stun:stun.l.google.com:19302"},{"urls":"turn:turn.example.com:3478","username":"user","credential":"pass"}]' python3 server.py
```

## 環境変数

| 変数 | 既定値 | 説明 |
| --- | --- | --- |
| `PORT` | `8000` | 待ち受けポート |
| `HOST` | `0.0.0.0` | 待ち受けアドレス（自分の PC だけなら `127.0.0.1`） |
| `AFTERCLASS_DATA` | `./data.json` | データの保存先 |
| `SSL_CERT` / `SSL_KEY` | なし | 指定すると HTTPS で起動 |
| `ICE_SERVERS` | Google の STUN | WebRTC の ICE サーバー（JSON） |

## 注意

- 通話は参加者全員が直接つながる方式（メッシュ）なので、快適なのは 4〜5 人くらいまでです。
- リマインダーはアプリを開いている間に通知されます。
- 学校の友だち向けの小規模利用を想定しています。インターネットに公開する場合は HTTPS 化とアカウント管理の強化を行ってください。
